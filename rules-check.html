Firestore rules check

This page tests your real database rules from your browser. Nothing to install. It signs in as two logins, tries about 40 things that should be allowed or refused, then cleans up after itself.

If it says a password was not accepted, it now names which login. Tip: type the passwords yourself (browsers sometimes fill saved ones into the wrong box).

Use a dedicated test participant (create one in the admin console: role Individual). For a minute the page changes that person's access and scoring settings to test them, then puts them back exactly as they were. Passwords are used only for this run and are not stored. The page leaves one or two harmless lines in the Audit tab, because the audit log cannot be deleted by design.
